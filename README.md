One original funny, true line (151 characters) for the make.fun "The Most Boring Object, Reviewed in One Line" bounty. A judge reads entries two at a time and picks the funnier, truer one — this entry's joke is the doorstop's own dullness: one job, zero recognition, and it still gets blamed when the door slams shut.

> The doorstop has exactly one job — hold the door open — and spends its entire career being kicked, ignored, and blamed anyway when the door slams shut.

## Run it

```sh
node main.ts
```

It prints the line and writes the identical text to `/output/entry.txt` (or `$OUTPUT_PATH` when set). It validates the entry first: 1–200 characters, a single line, not only whitespace, and verifies the written file round-trips identically. Deterministic — no randomness, no network, no clock.
